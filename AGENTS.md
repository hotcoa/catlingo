# AGENTS.md

Rules for any AI agent (GitHub Copilot, Claude, or others) working in this repository.
Follow these on every task unless the user explicitly overrides them.

## Rules

1. **Responsive on both desktop and mobile.**
   Every change must keep the page looking good and working well on both desktop and
   mobile. Verify both viewports before considering a task done — don't fix one and
   break the other.

2. **Preserve the user's French content — especially intermediate.**
   The French content already contains the user's personal learning notes and common
   phrases. Whenever you make changes, keep this existing French content intact. Be
   especially careful with the **intermediate** level. Do not rewrite, replace, or
   delete the user's French material unless they explicitly ask you to.

3. **Review for well-factored, efficient code when you build.**
   When you build or change anything, review the result to make sure the code is
   well-factored, clean, and efficient — not just functional. Avoid duplication and
   unnecessary complexity.

4. **Every language must sound natural to a native speaker.**
   All content for each existing language — and any new language added in the future —
   must sound natural in that language. Write like a native speaker, not like a
   translation.
